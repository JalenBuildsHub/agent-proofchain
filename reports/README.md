# Evaluation reports

Reports contain synthetic fixture identifiers, expected and actual decisions, reason codes,
and content hashes. They do not contain raw request content.

The `synthetic-v0.1` pilot is a deterministic package smoke test, not evidence of broad
prompt-injection coverage. Future public benchmarks must add independent fixtures, obfuscated
attacks, model-mediated trajectories, latency, and documented false-positive/false-negative cases.
