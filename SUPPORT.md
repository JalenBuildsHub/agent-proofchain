# Support

Agent ProofChain is an early open-source project. Support is community-based and best effort.

## Questions and integration help

Use GitHub Discussions when available, or open a regular issue using the question or feature template. Include:

- the Agent ProofChain version or commit;
- Python and operating-system versions;
- the command or API being used;
- a minimal synthetic reproduction;
- expected and observed behavior;
- relevant reason codes or privacy-safe receipts.

Do not post credentials, customer data, private prompts, internal repository paths, or production incident transcripts.

## Bugs

Use the bug-report issue form. A useful report includes a deterministic reproduction and explains whether the problem affects admission decisions, receipt integrity, privacy, portability, or documentation.

## Security vulnerabilities

Do not open a public issue. Follow `SECURITY.md` and report privately to `contact@jalenbuilds.com`.

## Commercial support

No commercial support commitment is included with the open-source package. Any future managed service, enterprise integration, or support offering will be documented separately and will not change the open-core verification boundary.
