# Security policy

Please report suspected vulnerabilities privately to `contact@jalenbuilds.com`.
Do not include production credentials, private prompts, customer data, or live exploit payloads.

We aim to acknowledge reports within five business days. Coordinated disclosure timing will be
agreed with the reporter based on severity and availability of a fix.

Security support currently covers the maintained Python 3.11 through 3.14 families on the latest
reviewed source. The package is not currently published on PyPI; similarly named registry packages
must not be treated as Nymrel releases without repository-linked provenance.
